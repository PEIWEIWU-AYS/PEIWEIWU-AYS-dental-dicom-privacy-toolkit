# Project Charter

## Problem

Dental clinics increasingly need to share imaging data for consultation, referral, research, and AI-assisted workflows, but DICOM files can contain sensitive metadata and require careful privacy controls.

## Proposed Direction

Build a synthetic-data-only toolkit that demonstrates dental DICOM inspection, anonymization, encrypted packaging, and audit reporting.

## Intended Users

- Dental clinics exploring secure imaging workflows
- Researchers studying imaging privacy
- Developers building privacy-preserving DICOM tools

## Non-Goals

- This project is not a clinical device.
- This project does not provide medical advice.
- This project must not process real patient data without separate privacy, legal, and security review.
