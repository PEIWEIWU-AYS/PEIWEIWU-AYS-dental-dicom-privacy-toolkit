# Support | 支持说明

This repository is intended for open-source discussion, synthetic demonstrations,
and research-oriented dental imaging privacy workflows.

## Where To Ask

- Use GitHub issues for reproducible bugs, documentation gaps, feature requests,
  and safety questions.
- Use discussions only after they are enabled on the repository.
- Keep questions specific and include command output when possible.

## Before Asking

Run:

```bash
ddpt doctor
ddpt macbook validate . --out macbook-validation-run --no-check-remote
```

Then include:

- macOS/Python version
- command that failed
- expected behavior
- actual behavior
- synthetic reproduction steps

## Do Not Share

Do not attach real DICOM, CBCT files, radiographs, intraoral photos, PDFs,
spreadsheets, screenshots, clinic exports, consent forms, credentials, or private
manuscript drafts.

## Boundary

This project cannot provide medical, legal, regulatory, insurance, or production
security advice. It provides local synthetic workflow evidence for software
development and review.
